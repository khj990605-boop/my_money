나의 생활비 v3
- 금액 입력 자동 쉼표 및 6개 빠른 누적 버튼, 초기화
- 월급 관리: 실수령액, 생활비 예산 자동 연동, 고정/예정 지출 자유 입력, 막통장 이체 예정액 계산, 실제 이체 완료 금액 기록, 월별 저장, 전월 항목 복사
- JSON 백업 v3에 월급 기록 포함, v1/v2 백업도 복원 가능
- IndexedDB 저장소 이름은 기존과 동일하게 유지하므로 동일 주소 업데이트 시 기존 기록 보존

업데이트 순서: 1. 기존 앱에서 JSON 백업 2. ZIP 압축 해제 3. 저장소 루트에 파일 덮어쓰기 업로드 및 커밋 4. GitHub Pages 배포 완료 확인 5. 앱 재실행 (구버전이면 완전히 종료 후 재실행)
주의: 앱 삭제/브라우저 데이터 삭제는 기존 기록을 지울 수 있습니다. 월급 관리 계산은 은행 계좌와 연결되지 않으며 이체를 실행하지 않습니다.
