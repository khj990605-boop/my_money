나의 생활비 PWA v2 (달력형)

1. ZIP 압축을 풀어 폴더 안 파일들을 GitHub 저장소 루트에 올리세요.
2. Settings > Pages > Deploy from a branch > main / (root) 설정.
3. 생성된 HTTPS 주소를 갤럭시 Chrome에서 열고 메뉴 > 홈 화면에 추가 > 설치.
4. 기록은 해당 브라우저의 IndexedDB에 저장됩니다. GitHub에 지출내역이 자동 업로드되지 않습니다.
5. 설정·백업에서 JSON 백업을 정기적으로 다운로드하고 개인 저장소에 보관하세요.
6. JSON 백업은 암호화되지 않습니다. GitHub 공개 저장소에 절대 업로드하지 마세요.
7. 기존 v1과 동일한 주소에서 사용하면 동일한 IndexedDB를 읽습니다. v1 백업 복원도 지원합니다.
8. 이전 v1의 현금 항목은 v2에서 계좌이체로 매핑됩니다. 이전 데이터가 있으면 먼저 백업하고 확인하세요.
9. 앱 업데이트는 같은 GitHub 저장소 파일을 교체하여 배포합니다. 배포 후 앱을 다시 열어 주세요.
10. 테스트: 지출 입력/수정/삭제, 달력 월 이동, 분석, JSON 백업 및 복원 확인 후 본격 사용하세요.
